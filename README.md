# 🏍️ QuickMoto AI Garage — Smart Two-Wheeler Workshop & Diagnostics

> A modern, responsive web application for motorcycle breakdown diagnosis, transparent cost estimation, digital inspections, 24/7 emergency roadside rescue, and workshop bay management.

## ✨ Features

- 🧠 **AI Symptom Diagnostics & Instant Estimator:** Accurately diagnoses common motorcycle problems (starting issues, brake failure, mileage drop, chain slack, engine overheating) and produces itemized labor & spare parts cost breakdowns.
- 🚨 **24/7 SOS Breakdown Rescue:** Instant emergency towing and roadside mechanic dispatch with live status updates.
- 🛵 **Doorstep Pickup & Delivery:** Easy scheduling modal for convenient two-wheeler pickup and drop-off.
- 📋 **21-Point Digital Inspection:** Interactive safety and maintenance checklist with health rating calculations.
- 📊 **Live Workshop Bay Kanban:** Track real-time service status (Queue, Diagnostics, Servicing, Quality Check, Ready).
- 🌓 **Aesthetics & Accessibility:** Built-in Dark / Light mode toggle, audio feedback cues, and mobile-friendly responsive layout.
- 💳 **Direct Payment & UPI Simulation:** Seamless billing, discounts, and payment invoice generator.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern Vanilla JavaScript (ES6+ Modules)
- **Styling:** Custom CSS3 Design System + Tailwind CSS
- **Design Tokens:** Dark/Light Theme variables, glassmorphism, responsive grid
- **Deployment:** GitHub Pages / Static Web Hosting

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muhammedhshamsudheen/Quick-Moto-Ai-Garage.git
   cd QuickMoto-Ai-Garage
   ```

2. **Run with any static server:**
   ```bash
   # Using Python
   python3 -m http.server 5173

   # Or using Node.js / npx
   npx serve .
   ```

3. **Open in browser:**
   ```
   http://localhost:5173
   ```
